# 3차 시안(현재 사이트 화면)

2026-11-13 부터 3차 시안이 실제 사이트 화면입니다. 시안 비교 버튼(VersionSwitcher)은 삭제했고,
고르던 값은 `useVersion.js` 에 고정했습니다(시안 = 3차 시안, 메인 헤더 = 투명, 푸터 = 차콜, 색 구성 = 연한 회색, 첫 화면 = 실제 사진 3장).

| 항목 | 위치 | 내용 |
|---|---|---|
| 화면 설정(고정값) | `useVersion.js` | 위 확정값 |
| 시안 목록 | `registry.js` | 원본 / 3차 시안(`v3`) — 원본은 코드만 남아 있고 화면에는 나오지 않음 |
| 공용 헤더·푸터·카카오 버튼 | `common/` | |
| 메인 | `v3/Main.vue`, `v3/main/*` | 메인 섹션 |
| 하위 페이지 | `v3/pages/*` | 교육원 소개 · 교육안내 · 수강현황 · 수강후기 · 자주묻는질문 · 수강신청문의 |
| 디자인 규칙 | `v3/tokens.css` | 글자 크기 · 색 · 간격 · 버튼 · 움직임 값(`.ver-v3` 안에서만 적용) |

- 하위 페이지는 `src/router/index.js` 에서 `versioned(키, 원본)`(`versionedPage.js`)으로 감싸 두었습니다.
  3차 시안 `registry.js` `pages` 에 같은 키가 있으면 3차 시안 페이지, 없으면(관리자 화면 등) 원본 페이지가 나옵니다.
- 관리자 화면(`src/views/admin/*`)은 원본 그대로 씁니다.

나중에 정리할 때: 3차 시안 파일을 원래 자리(`src/components`, `src/views`)로 옮기고, 원본 화면 파일 · `registry.js` ·
`versioned()` 감싸기 · 이 폴더를 지웁니다. 함께 고칠 곳: `src/App.vue`, `src/router/index.js`.
