# 시안 비교 (임시)

리디자인 시안(3차 시안)을 화면 왼쪽 아래 비교 버튼으로 원본과 바꿔 가며 보기 위한 임시 폴더입니다.
시안이 확정되면 확정본을 원래 자리(`src/components`, `src/views`)로 옮기고 이 폴더는 지웁니다.

| 항목 | 위치 | 내용 |
|---|---|---|
| 원본 | `src/components/Header.vue`, `Footer.vue`, `src/views/**` | 운영 중인 화면 |
| 시안 목록 | `registry.js` | 원본 / 3차 시안(`v3`) — 1·2차 시안은 11/13 삭제 |
| 시안 공용 헤더·푸터·카카오 버튼 | `common/` | 헤더·푸터 색은 비교 버튼에서 선택 |
| 3차 시안 메인 | `v3/Main.vue`, `v3/main/*` | 메인 섹션 |
| 3차 시안 하위 페이지 | `v3/pages/*` | 교육원 소개 · 교육안내 · 수강현황 · 수강후기 · 자주묻는질문 · 수강신청문의 |
| 디자인 규칙 | `v3/tokens.css` | 글자 크기 · 색 · 간격 · 버튼 · 움직임 값(`.ver-v3` 안에서만 적용) |

- 비교 버튼은 `npm run dev` 로컬 화면에서만 보입니다. 배포본에서는 주소 끝에 `?preview` 를 붙였을 때만 보이고, 그 외에는 항상 원본이 나옵니다.
- 하위 페이지는 `src/router/index.js` 에서 `versioned(키, 원본)`(`versionedPage.js`)으로 감싸 두었습니다.
  지금 고른 시안의 `registry.js` `pages` 에 같은 키가 있으면 시안 페이지, 없거나 원본을 고르면 원본 페이지가 나옵니다.
- 시안 값은 `.ver-v3` 로 묶여 있어 원본 화면에 영향을 주지 않습니다.
- 새 시안 추가: `<id>/Main.vue` 를 만들고 `registry.js` 에 한 줄 추가.

정리할 때 함께 되돌릴 곳: `src/App.vue`(헤더·푸터 선택, 비교 버튼), `src/router/index.js`(`/` 경로, `versioned()` 감싸기).
